# Админ-панель UstaGo

## Роли

| Роль | Что может |
|---|---|
| `superadmin` | всё: настройки, справочники, логи, бэкапы, управление ролями |
| `moderator` | мастера (одобрить / забанить / аккредитация), отмена заказов, ответы в поддержке |
| `finance` | баллы мастеров, заявки на пополнение, массовые начисления |

Просматривать пользователей, заказы, статистику и поддержку могут все администраторы. Админы, созданные до появления
ролей, считаются `superadmin`. Роль меняется в разделе «Админы» (свою роль менять нельзя) или при создании:

```bash
PYTHONPATH=. uv run python scripts/set_admin.py <логин> <пароль> [superadmin|moderator|finance]
```

Права проверяются на сервере (`require_role` в `admin_api/main.py`); скрытые кнопки во фронтенде нужны только для удобства.

## Вход и защита

* Пароль + одноразовый код 2FA из Telegram (5 минут, 5 попыток, код сгорает после использования).
* Блокировка на 15 минут: 5 неудачных попыток для пары «логин + IP», 20 для одного IP, 30 для одного логина.
* Счётчики и коды хранятся в Redis (`REDIS_URL`); без Redis используется память процесса и в лог пишется предупреждение.
* За nginx/Cloudflare включите `TRUST_PROXY_HEADERS=1`, иначе все запросы будут «с одного IP».
* Обязательные переменные `.env`: `JWT_SECRET_KEY` (32+ символа), желательно `CORS_ORIGINS=https://admin.example.com`.

## Возможности

* Пользователи: серверный поиск (имя, @логин, телефон, ID, Telegram ID), фильтры, карточка с историей баллов, заказов и откликов, экспорт CSV.
* Заказы: поиск, фильтры по статусу/категории/датам, отмена заказа админом (возврат баллов мастерам + уведомления), экспорт CSV.
* Дашборд: воронка «заявка → отклик → мастер выбран → завершён» за 7/30/90 дней, время до первого отклика, счётчик обращений без ответа.
* Поддержка: список обращений, ответ из панели (уходит пользователю через бота; «отвечено» ставится только если Telegram доставил сообщение).
* CSV открывается в Excel (UTF-8 с BOM, разделитель `;`), ячейки, начинающиеся с `= + - @`, экранируются.
